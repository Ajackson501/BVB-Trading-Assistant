Agent B reads the chart in this order: direction and structure → 8/20/200 alignment → narrow/trending/wide state → location near the 8/20 or a clean breakout level → named event → confirmation → risk. He favors fast momentum and breakout continuation, but avoids late entries after the move has already stretched.
